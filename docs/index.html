Instalação

Configure no seu servidor

O TKT é auto-hospedado. Crie uma aplicação no Discord Developer Portal e siga o README do projeto para iniciar o bot.

Configurar a equipe

Use /tkt configurar para definir o cargo de suporte, a categoria dos canais e o canal de registros.

Publicar um painel

Use /tkt painel no canal onde deseja receber pedidos. O botão abre o formulário do ticket.

Atender e encerrar

Use os botões do canal ou o comando /ticket para gerenciar o atendimento.
